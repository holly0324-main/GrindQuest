# GrindQuest PWA v0.2

スマホ縦持ちを主役にした、分岐マップ型ダンジョングラインドRPGのプロトタイプです。
前に検討していた「PC向けJRPGコマンド戦闘ローグライク」とは別方向にし、こちらはスマホで短時間に「進む / 休む / 撤退する」を判断するゲームとして設計しています。

## v0.2 の中核

- Slay the Spireライクな縦型分岐マップ
  - 戦闘
  - 強敵
  - 採取
  - 休憩
  - ボス
- 探索途中でいつでも撤退可能
  - 探索中のEXP・素材は「未確定の戦果」
  - 撤退すると戦果を確定して持ち帰る
  - 全滅すると未確定の戦果を失う
- HP / MP の自動回復を廃止
  - ダンジョン開始時に回復しない
  - 戦闘終了時に回復しない
  - レベルアップ時に回復しない
  - 撤退・踏破時にも回復しない
  - 町の「休む」操作、またはマップ上の休憩地点でのみ回復
- お金を現在のゲームループから削除
  - 敵のゴールドドロップなし
  - 放置探索のゴールド報酬なし
  - 鍛冶は素材のみで作成
- 放置探索
  - 経過時間からEXP・素材を計算
  - 最大8時間
  - HP / MP には影響しない
- IndexedDBセーブ + localStorageフォールバック
- セーブJSON Export / Import
- Web App Manifest + Service Worker

## 戦闘

DQライクな1対1コマンド戦闘の仮実装です。

- こうげき
- 火炎斬り
- ホイミ
- ぼうぎょ
- 薬草

能力選択などのローグライト強化はまだ入れていません。先にダンジョンマップと撤退判断を成立させています。

## ローカルで起動

Service Workerを使うため `file://` 直開きではなくHTTPサーバーで開いてください。

```bash
python -m http.server 8080
```

その後 `http://localhost:8080/` を開きます。

## GitHub Pages

ビルド不要の静的構成です。

1. GitHubにリポジトリを作成して、この中身をpush
2. `Settings` → `Pages`
3. `Build and deployment` を `Deploy from a branch`
4. `main` / `/(root)` を選択

プロジェクトページでも動くようURLは相対パスで統一しています。

## データ構造

- `src/data/gameData.js`: 敵、ダンジョン、素材、装備、レシピ
- `src/core/game.js`: 戦闘、分岐マップ、撤退、放置、鍛冶
- `src/ui/app.js`: スマホUI

将来はデータを `data/enemies/*.json` 等へ分割し、ファイル追加だけで登録できるローダーへ移行する想定です。
