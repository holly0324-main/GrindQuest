# GrindQuest PWA v0.13

スマホ縦持ち前提の周辺フィールド探索・採集・帰路管理RPGプロトタイプです。

## v0.13 — Rnレア度 / 図鑑

### レア度を `Rn` へ統一

従来の `コモン / アンコモン / レア / エピック` を廃止し、装備Rankと同じ数値レア度へ統合しました。

- `R0` : 基本的な品
- `R1` : 一段希少な品
- `R2` : 現在地域の上位品
- `R3+` : 今後拡張可能

`品質0 / ☆1 / ☆2 / ☆3` はレア度とは別軸です。同じR2アイテムでも品質や装備の出来栄えは個体ごとに変化します。

### アイテム図鑑

`設定 > アイテム図鑑` を追加しました。

各項目には以下を表示します。

- アイコン / 図鑑No.
- 名前 / Rn
- 分類
- 効能・装備性能
- 基本売値（現在売却不可の品はその旨を表示）
- 寿命
- フレーバーテキスト

図鑑表示は `items / consumables / materials` の実データを参照するため、性能や価格を変更すると図鑑にも反映されます。

### モンスター図鑑

`設定 > モンスター図鑑` を追加しました。

- アイコン / 図鑑No.
- 討伐数
- HP / 攻撃 / 守備 / 素早さ
- 生息地域と活動時間帯
- 報酬枠数
- ドロップ品と `n/256` の抽選比率
- ドロップ個数
- フレーバーテキスト

討伐数は `encyclopedia.kills` としてセーブされます。v0.12以前のセーブは0体から記録開始します。

### アイコン短押し長押し

以下の画面では、アイテムアイコンを約0.36秒長押しすると図鑑詳細をその場に表示できます。

- 村 / 探索中のバッグ
- 通常倉庫
- 生鮮倉庫
- 装備画面
- 道具屋や生産画面の対応アイコン

戦闘中は敵アイコン長押しでモンスター詳細も確認できます。

詳細カードは枠外をタップすると閉じます。
