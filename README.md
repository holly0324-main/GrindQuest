# GrindQuest PWA v0.5

スマホ縦持ち前提の、周辺フィールド探索・採集・帰路管理・ターン制コマンド戦闘RPGのプロトタイプです。

## v0.5 の主な変更

### 戦闘UI

- エンカウント時はフィールド暗転 → 専用戦闘画面
- コマンドを「ボタン」として押しやすく再設計
- こうげき / とくぎ / じゅもん / ぼうぎょ / 薬草 / ポーション
- 1コマンドターン = 1 world step
- プレイヤーHP/MPをゲージ表示
- 攻撃時に斬撃、敵揺れ、ダメージ数字を表示
- 敵攻撃時はプレイヤーステータス側を赤く揺らす

### EXP

- 戦闘勝利時に即時反映
- 新しい場所への初到達でもEXP
- 採集・採掘・釣り・木こりでもEXP
- 一部の探索イベントでもEXP
- 全滅しても獲得済みEXPは失わない
- レベルアップしても現在HP/MPは回復しない

### 探索UI

- 探索中HUDをコンパクト化
- 現在地に `🧑‍⚔️` マーカー
- 採取 / 採掘 / 釣り / 伐採ボタンを地図右上へオーバーレイ
- 探索中にバックパックを開ける
- 薬草・ポーション使用は2step消費
- ルーラのポーションもバックパック内へ移動
- キャンプもバックパック内の行動へ移動
- 地図下の旧キャンプ/採集UIは削除

### 村のアイテム画面

`アイテム` タブから施設に入る方式へ変更。

- 道具屋
- 倉庫・素材売却

道具屋は独立した店内画面として表示します。

### 鍛冶

同じ装備でも作り方を選べます。

- **鍛冶屋に頼む**: 素材を渡し、60step後に完成
- **自分で打つ**: タイミング系ミニゲームを3回行い、12step消費して完成

鍛冶依頼は `timedProcesses` を使うため、探索・睡眠・戦闘などで世界時間が進むと完成します。

### 調合

初期レシピ:

- 薬草 ×1
- 森キノコ ×1
- 瓶代 20G
- 8step
- → ポーション ×1

品質判定用の調合ミニゲームは後から追加予定です。

### 装備画面

DQ9を意識したスロット型UIへ変更。

- 武器
- 盾
- 頭
- からだ上
- 腕
- からだ下
- 足
- アクセ

現状の実装装備は武器・からだ上が中心ですが、内部状態は全スロットを持っています。v0.4以前の `armor` セーブは `body` へ自動移行します。

## 継続しているシステム

- 27地点の双方向周辺マップ
- 朝 / 昼 / 夜を各30stepで管理
- 生鮮品の寿命をstep単位で管理
- 2徹夜目以降の疲労ペナルティ
- セーフティ / 準セーフティでのキャンプ
- バッグ容量
- 素材売却が主な金策
- 放置探索はUIから封印、コードのみ保持

## テスト

```bash
npm test
```

v0.5では、従来の時間・寿命・キャンプ・帰路テストに加えて、即時EXP、レベルアップ非回復、探索アイテムのstep消費、鍛冶依頼、自作鍛冶、調合、主要UIの静的レンダリングを確認しています。

## ローカル起動

```bash
python -m http.server 8080
```

`http://localhost:8080/` を開いてください。

## GitHub Pages

ビルド不要です。リポジトリへ中身をpushし、`Settings > Pages > Deploy from a branch > main / (root)` で公開できます。
