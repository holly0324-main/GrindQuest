# GrindQuest PWA v0.7

スマホ縦持ち前提の「周辺フィールド探索・採集・帰路管理・コマンド戦闘RPG」プロトタイプです。

フィールドは実際の村・森・川・山・遺跡周辺をノードと線に圧縮した地図として扱います。ノードはイベントではなく**場所**で、同じ場所を巡回して魔物を探したり、固定採集地点へ通ったり、帰路を歩いて村へ戻ったりします。

## v0.7 の主な変更

### 世界時計: 1フェーズ 50step

- 朝 50step → 昼 50step → 夜 50step
- 150stepで翌日
- 移動、巡回、戦闘、採集、アイテム使用、睡眠、鍛冶を同じ時計で管理
- 従来の30step基準から50step基準へ変更

### 村への帰還

探索開始地点のミナト村は通常のマップノードとして残ります。

- 外から村ノードへ移動しただけでは探索終了しない
- 村にいる状態でもう一度**現在地の村アイコンをタップ**すると帰還
- 帰還時、`material` と `valuable` タグのアイテムは空き容量の範囲で自動的に倉庫へ送る
- `adventure` タグの薬草、ポーション、ルーラ等はバッグに残す

### 戦闘: 逃げる・素早さ行動順

- `にげる` コマンドを追加
- 同一戦闘内の逃走試行回数を `n` として成功率は `n / 3`
  - 1回目 1/3
  - 2回目 2/3
  - 3回目 100%
- プレイヤーと敵の双方に素早さを持たせた
- 各ターンに小さな乱数補正を加えて先攻/後攻を決定
- 敵が先に動いてプレイヤーが倒れた場合、そのターンのプレイヤー行動はキャンセル

### モンスターの複数ドロップ

敵ごとに「何枠落とすか」と「各枠から何が出るか」を分離しました。

スライムの例:

- 1枠: 50%
- 2枠: 50%
- 1枠ごとの256分率
  - 薬草 8 / 256
  - スライムゼリー 247 / 256
  - スライムの核 1 / 256

同一戦闘で同じ素材が複数個出ることも、異なる素材が同時に出ることもあります。通常雑魚には原則2～5種類程度の候補を設定しています。

### アイテムタグと倉庫

スタックアイテムに次のタグを設定しています。

1. `adventure` - 冒険用アイテム
2. `material` - 製作用素材
3. `valuable` - 換金向けアイテム

倉庫表示は上記順でグルーピングし、同種では品質の高いものを優先します。

- 初期倉庫容量: 200
- 拡張: 320 → 500 → 800 → 1200
- 倉庫内の生鮮品はバッグの1/3速度で劣化
- 取り出した時に寿命表示を3倍する処理は行わない。残っている寿命をそのままバッグへ戻す
- `換金品を全て売る` を追加
- バッグ容量: 40 → 70 → 110

### 素材・換金品を大幅追加

スライムの核、獣毛、角、翼膜、夜光粉、ゴブリン布、古い小銭、狼皮、狼爪、胞子袋、硬石、岩トカゲの鱗、呪布、ゴーレム核片、インプ素材、古代の歯車、山猪素材、大蜂素材、洞蛾素材などを追加しました。

敵から直接Gは落ちません。素材・換金品を持ち帰って売ることが主な収入源です。

### 装備ランクと出来栄え

装備品を一意な個体として管理するよう変更しました。

- ランク0: 初期装備級
- ランク1: 現地域の通常装備
- ランク2: 現マップ帯の上位装備
- 現段階ではランク2を地域上限の目安としている

各装備個体には `workmanship`（出来栄え）0～3を保持します。

出来栄えに応じて基礎性能が少し伸び、さらに追加効果をデータ駆動で付与できる構造にしています。現在の追加効果候補には攻撃、防御、HP、素早さ、かしこさ、きようさ等があり、後から種類を追加できます。

装備画面から未装備の装備個体を売却できます。

### 鍛冶レシピの拡張

武器、防具、盾、頭、腕、下半身、足、アクセサリまでレシピを追加しました。

現在の地域で作れる上位例:

- 山割りの斧
- 晶鉄の剣
- 炎晶剣
- 魔力のローブ
- 岩鱗のよろい
- 鉄かぶと
- 鉄のこて
- 古跡のお守り

鍛冶屋への依頼は60step後に完成。自作鍛冶では出来栄えと追加効果を付与できる土台があります。

### 主人公の基礎パラメータ

主人公に以下を追加しました。

- たいりょく
- ちから
- すばやさ
- まりょく
- かしこさ
- ちしき
- きようさ

攻撃力は**ちから + 装備攻撃力**で算出します。

採集・採掘・釣り・木こりの生活スキルレベルアップでも関連能力が伸びます。採集品質は、生活スキルLv・きようさ・採取難度・ミニゲーム成績・小さな乱数を組み合わせて判定します。

### マップ・敵追加

既存地域の周辺を少し拡張しました。

追加地点例:

- 葦原
- 蜂の林
- 老樫の森
- 山猪の獣道
- 水晶棚
- 墓地
- 封印区画

追加敵例:

- 大蜂
- 山猪
- 洞窟蛾

既存敵にもすばやさと複数ドロップテーブルを設定しています。

## 既存の中核

- スマホ縦持ちUI
- 地図上の現在地表示
- 現在地タップによる1step巡回/エンカウント抽選
- 固定採集地点
- 採掘 / 釣り / 木こりミニゲーム
- 品質0 / ☆1 / ☆2 / ☆3
- 品質別・寿命別スタック
- 生鮮品の寿命
- 戦闘中の技 / 魔法 / 道具リスト
- 探索中バッグ
- セーフティ / 準セーフティキャンプ
- ルーラのポーション
- 村の道具屋 / 倉庫 / 鍛冶
- 即時EXPと非回復レベルアップ
- 放置要素はUIから封印したままコードのみ保持

## ローカル起動

```bash
python -m http.server 8080
```

`http://localhost:8080/` を開いてください。

## GitHub Pages

ビルド不要です。リポジトリへ中身をpushし、`Settings > Pages > Deploy from a branch > main / (root)` で公開できます。
