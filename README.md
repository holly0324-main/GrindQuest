# GrindQuest PWA v0.10

スマホ縦持ち前提の、周辺フィールド探索・採集・戦闘・生産を中心にしたPWA RPGプロトタイプです。

## v0.10 の主な変更

### 採集ミニゲーム → エンカウントの順序修正

採掘・釣り・木こりのミニゲームで、入力した瞬間に戦闘へ割り込む問題を修正しました。

現在は以下の順序です。

1. ミニゲーム入力を確定
2. 判定バーなどのアニメーションを停止
3. 採集結果を表示
4. ミニゲーム画面を閉じる
5. その後に周辺エンカウント抽選
6. 当選時のみ戦闘画面へ遷移

採集結果と戦闘開始を別処理にしたため、後から採集演出を長くしても戦闘が途中へ割り込みません。

### アイテムレア度

品質とは別に、アイテム定義へレア度を追加しました。

- コモン
- アンコモン
- レア
- エピック

装備はRank、素材は価値を基準に暫定設定しています。UIではバッグ・倉庫・店・装備・生産品などに表示します。

### 生産メニューの階層化

`生産` を開くと、最初に以下を選びます。

- 鍛冶
- 調合

鍛冶はさらに次のカテゴリに分かれます。

- 武器
- 盾
- 頭
- からだ上
- 腕
- からだ下
- 足
- アクセ
- 中間素材

カテゴリを選んだ後だけ、その種類のレシピ一覧を表示します。

### 材料不足表示

鍛冶・調合の材料は、たとえば以下のように現在数と必要数を表示します。

`鉄鉱石 2/4`

不足している材料・瓶代は赤表示になります。

### 中間素材

以下を追加しました。

- 鉄のインゴット
- なめし革
- 強化木材
- 晶石の粉
- 薬草エキス

Rank 1後半～Rank 2装備の一部は、中間素材を作ってから鍛えるレシピへ変更しています。

### 暫定調合

調合を再開し、仮ミニゲームを追加しました。

現在は3回のタイミング判定で、

1. 刻む
2. 混ぜる
3. 火を止める

を行い、平均成績から品質0～☆3を決定します。

初期レシピ:

- 薬草エキス
- ポーション
- 濃縮ポーション

材料品質を個別に選択するUIは、将来、倉庫の `アイテム → 品質 → 寿命` と同じ階層UIを流用する予定です。

- 周辺マップとローカルエリア
- フィールド / ダンジョン属性
- ランダムエンカウント / シンボルエンカウント / 復活ボス
- 足踏みによる巡回狩り
- 逃走 1/3 → 2/3 → 3/3
- 複数枠モンスタードロップ
- 品質0 / ☆1 / ☆2 / ☆3
- 採集 / 採掘 / 釣り / 木こりLv
- 生鮮品の寿命
- 通常倉庫 / 生鮮倉庫
- 装備Rank / 出来栄え / 追加効果
- 鍛冶屋への60step依頼
- 自作鍛冶ミニゲーム
- PWA / IndexedDBセーブ / オフラインキャッシュ

## ローカル起動

```bash
python -m http.server 8080
```

`http://localhost:8080/` を開いてください。

## GitHub Pages

ビルド不要です。リポジトリへ中身をpushし、`Settings > Pages > Deploy from a branch > main / (root)` で公開できます。
