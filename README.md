# GrindQuest PWA v0.11

スマホ縦持ち前提の周辺探索・採集・生産・コマンド戦闘RPGプロトタイプです。

## v0.11 — 釜グル調合

ポーション系の手動調合を、旧3回タイミングゲームからリアルタイムの「窯を指でぐるぐる混ぜる」操作へ置き換えました。

### 手動調合

- 温度管理
  - 火力スライダーで加熱量を調整
  - 温度は `performance.now()` の実経過時間から更新
  - 素材ごとに適温と許容範囲を保持
  - 素材投入時に釜温度や安定度が変化
- 素材投入
  - レシピ素材を好きなタイミングで投入
  - 素材ごとに適温、理想攪拌速度、理想回転方向、抽出速度を設定可能
- 釜グル
  - Pointer Events (`pointerdown / pointermove / pointerup`) を使用
  - 円運動の角度差から回転方向・RPS・総回転量を取得
  - 半径のブレから円軌跡の安定度を評価
  - 攪拌状態と温度から各素材の抽出効率を計算
- 任意終了
  - 必要素材を投入し、最低抽出ラインを超えるといつでも完成可能
  - 早めに安全に終えるか、さらに煮詰めて高評価を狙える
  - 過抽出・高温・長時間放置で劣化と安定度低下

### FPS非依存

- シミュレーション時計: `performance.now()`
- 状態更新: 125ms周期（約8Hz）
- 数値積分: 最大100ms単位に分割
- 見た目の釜回転: `requestAnimationFrame`
- 指の軌跡: `pointermove` を高頻度取得

端末の表示FPSと調合品質判定を分離しています。

### きようさ

`きようさ` は手動調合の品質へ直接加算しません。

代わりに以下の許容範囲が広がります。

- 適温
- 理想攪拌速度
- 回転操作
- 円軌跡

簡易調合では操作がないため、きようさから最低保証品質を決定します。

### 3つの調合モード

- **手動調合**: プレイヤースキルで ☆3 を狙える
- **簡易調合**: 1個を即処理。きようさ依存の最低保証品質
- **一括調合**: 現在は最大10個をまとめて簡易処理

一括時の世界stepは個数に比例しつつ、1個ずつ作るより圧縮されます。数値は仮です。

### 将来の調合魔法

`src/core/alchemy.js` に釜状態へ作用するEffect構造を用意しています。

現時点で拡張可能なEffectタイプ:

- `heat_hold` — 保温
- `chill` — 急冷
- `extract_boost` — 抽出促進
- `stabilize` — 安定化

UI・MP消費・習得条件などはまだ未実装です。
