# GrindQuest PWA v0.9

スマホ縦持ち前提の、周辺フィールド探索・採集・ダンジョングラインドRPGのプロトタイプです。

## v0.9 — ローカルエリア

周辺地図は「村・森・川・山・遺跡の位置関係を大幅に簡略化した広域図」のまま維持し、いくつかの地点からさらに内部へ入れるようにしました。

入った先を **ローカルエリア** と呼び、内部データでは `type: field | dungeon` を持ちます。

- **フィールド**: 採集・釣り・採掘など寄り道主体の小規模エリア
- **ダンジョン**: 複数区画、階層移動、ランダム/シンボルエンカウント、最奥ボスを持てる迷宮型

この差は今後さらに拡張できるよう、最初から属性として分離しています。

## エンカウント

### 周辺地図

従来どおり移動・足踏みで抽選します。

### ローカルエリア

- 移動コストが `0step` のフィールドでは、移動だけでは基本的にエンカウントしません
- 移動コストが `1step` のエリアでは、そのstep進行時にランダムエンカウント判定があります
- 採集 / 採掘 / 釣り / 伐採を行うと、作業後に足踏み相当のエンカウント判定を行います
- マップ上で回復アイテムを使った場合も、時間経過後に足踏み相当のエンカウント判定を行います

つまり安全な採掘場でも、何度も作業すれば魔物に気づかれる可能性があります。

## シンボルエンカウント

ダンジョン内の一部ノードには敵シンボルが存在します。

- シンボル地点へ移動すると戦闘
- 逃走した場合はシンボルが残る
- 通常シンボルは倒すと、その探索中は消滅
- ボスは撃破時刻を世界側に記録し、一定step後に復活

現在の仮復活周期:

- 鉱脈ゴーレム: 300step
- 灰冠の守護者: 360step

## 採集回数

周辺地図上の簡易採集は従来どおり、その探索で基本1回です。

ローカルエリア内では地点ごとに回数を持ちます。

```text
西鉱脈      3回
崩石棚      2回
奥鉱脈      2回
```

使用回数はローカルエリアを出ても同じ探索中は保持され、次の探索開始時にリセットされます。
