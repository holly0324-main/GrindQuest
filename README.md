# GrindQuest PWA v0.12

スマホ縦持ち前提の周辺フィールド探索・採集・帰路管理RPGプロトタイプです。

## v0.12 — 釜グル調合の手触り変更

### 全素材投入でいつでも「調合完了」

手動調合では、レシピの素材をすべて釜へ投入した時点で `調合完了` ボタンが有効になります。
抽出度・安定度などの内部値を満たすまで待つ必要はありません。

- 早く切り上げることもできる
- 状態が悪ければ `失敗ポーション` / `濁った薬液` になる
- 良い状態なら品質0〜☆3の完成品になる
- さらに煮詰めて高品質を狙うこともできる

### 内部ゲージを非表示

抽出度・安定度・劣化度は内部計算のみにしました。
プレイヤーは数値ではなく釜の見た目を読みます。

- ☆0以上の完成品が見込める状態: 釜の周囲がキラキラする
- 状態が悪い: 液体が濁った茶緑系になる
- 状態が良くなるにつれて液色が澄む
- 高品質域は暖色系の輝きが強くなるが、正確な品質は完成まで非表示

### 少ない攪拌でも抽出

v0.11より抽出速度を高め、数回円を描くだけでも意味のある抽出が進むように調整しました。
攪拌し続けること自体が目的ではなく、温度・投入タイミング・回転速度・方向を合わせることを重視します。

### 素材投入による温度変化を時間効果化

素材を入れた瞬間に釜温度が飛ぶ仕様を廃止しました。
素材ごとに `℃/秒 × 持続秒数` の温度変化を持ち、複数素材の効果は加算されます。

例:

- 薬草: `-1.0℃/s × 3秒`
- 森キノコ: `-1.6℃/s × 4秒`
- スライムゼリー: `-2.2℃/s × 5秒`

内部データは `tempRateCPerSec` と `tempRateDurationMs` なので、将来 `ホカホカ石: +3℃/s × 50秒` のような素材もそのまま追加できます。

### 時間処理

- 状態更新: 約8Hz
- 時間差: `performance.now()`
- 描画: `requestAnimationFrame`
- 釜グル入力: `pointermove`
- 長いdtは100ms単位に分割して積分

端末の描画FPSに依存して品質が変わらない構造です。

### きようさ

手動調合では品質点を直接増加させず、適温・回転速度・軌跡の許容幅を広げます。
簡易調合 / 一括調合では最低保証品質に利用します。

### 将来の調合魔法

釜状態へEffectを追加する構造は維持しています。

- 保温
- 急冷
- 抽出促進
- 安定化
