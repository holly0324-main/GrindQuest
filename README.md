# GrindQuest PWA v0.19.1

スマホ縦持ち前提の探索・採集・生産・最大4人パーティ対応コマンドRPG PWA。

## v0.19.1 — First-get Presentation Hotfix

### 初ゲット演出

初入手は **1アイテムにつき1枚ずつ**、キュー順に連続表示する方式へ戻した。枠外をタップすると次の初入手へ進む。

戦闘FXや採集結果などでUIが短時間に再描画された際、同じキュー先頭のカードがDOM再生成されて登場アニメーションを繰り返し、二重表示のように見える問題を修正。同じ初入手レコードの登場アニメーションは一度だけ実行し、次のアイテムへ進んだ時だけ新たにアニメーションする。

### 敵モンスターLv

敵インスタンスに `level` を追加。同じモンスターでも出現場所に応じてLvと戦闘能力が変わる。

代表的な出現帯:

- 村はずれ / 川辺: Lv.1〜3
- 森: Lv.2〜4、稀にLv.5
- 山: Lv.2〜4、稀にLv.5
- 古跡: Lv.3〜4、稀にLv.5
- 旧鉱山深部 / 封印回廊深部: Lv.4中心、Lv.5が混ざりやすい
- 現在の深部ボス: Lv.5固定

各モンスター定義の既存能力を `baseLevel: 1` の基準値とし、Lv上昇時はHP/攻撃/守備/素早さを共通成長率で補正する。モンスター図鑑は基準能力と地域ごとの出現Lv帯を表示する。

### 戦闘EXPのレベル差補正

敵よりキャラクターのLvが高い場合、そのキャラクターが得る戦闘EXPを次で減衰する。

```text
Lv差 = 自分Lv - 敵Lv
倍率 = max(0, 1 - Lv差 × 0.10)
```

- 同Lv以下: 100%
- 1Lv上: 90%
- 2Lv上: 80%
- ...
- 10Lv以上上: 0%

複数人パーティでは**各キャラクターのLvで個別計算**する。敵の方が高Lvでも追加ボーナスはまだ付けない。敵Lvそのものによる基礎EXP増加も今回は行わない。

## v0.18 — Expedition Loop Foundation

v0.17の発見システムを利用して、**依頼を見る → 冒険 → 発見 → 帰還結果 → 冒険手帳 → 報酬/解禁 → 次の冒険**という最小ゲームループを追加。

### 1. 探索結果

探索開始時にセッション用 `state.run.summary` を作り、成果を取得時点で記録する。帰還時には `state.expeditions.lastResult` と履歴（最大20件）へスナップショット化。

表示項目:

- 最深到達地点 / 深度
- 探索step
- 戦闘回数 / 撃破数
- 獲得G / 獲得EXP
- 獲得アイテム（品質・個数）
- `NEW` 初入手
- `NEW` 初遭遇
- 今回増えた知識

アイテムを途中で使用したり、帰還時に倉庫へ自動収納されても「今回獲得したもの」は結果から消えない。

### 2. 冒険手帳

村に `📓 冒険手帳` を追加。既存の設定内「図鑑」は**全データを参照できる資料**として維持し、冒険手帳だけを発見済み限定にした。

現在の章:

- モンスター
- アイテム
- 装備
- 素材

`game/discovery` には将来用として `recipes / people / places / rumors / events` の汎用知識レコードも用意済み。

### 3. 依頼掲示板

村にデータ駆動の `📌 依頼掲示板` を追加。現在は動作確認を兼ねて4件。

- スライム3体討伐
- スライムゼリー5個納品
- 鉄鉱石の発見
- 旧鉱山最奥ボス攻略

objective handler:

- `kill`
- `deliver`
- `discover`
- `dungeon`
- `story`

reward handler:

- `gold`
- `item`
- `recipe`
- `knowledge`
- `story`

依頼ごとの専用処理を戦闘や探索へ書かず、`src/data/quests/quests.js` の定義を共通エンジンが評価する。

鉄鉱石発見依頼では報酬として「鉄のインゴット」レシピを解禁するため、依頼報酬が実際に次の鍛冶へ繋がる。

## アーキテクチャ

詳細は [`ARCHITECTURE.md`](./ARCHITECTURE.md)。v0.18で追加した主要ドメイン:

```text
src/data/quests/       # 依頼定義
src/game/expedition/   # 1探索の成果記録・帰還スナップショット
src/game/handbook/     # 発見済みのみの冒険手帳projection
src/game/quests/       # 汎用objective/reward engine
```
