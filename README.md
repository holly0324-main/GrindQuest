# GrindQuest PWA v0.6

スマホ縦持ち前提の、周辺フィールド探索・採集・帰路管理・ターン制コマンド戦闘RPGプロトタイプです。

## v0.6 の主な変更

### 足踏み / 周辺巡回

探索マップで**現在地そのものをタップ**できるようになりました。

- 1回 = 1 world step
- 現在エリアのエンカウント抽選を再実行
- 内部的には「その場所の周辺を短く巡回している」扱い
- 山の敵ドロップなど、特定地域のモンスターを狙って狩り続けられる
- 低確率で小イベントも発生

隣接地点への移動より少ないstepで、同じ地域の遭遇抽選を繰り返せます。

### 品質 4段階

採集品・素材・消費アイテムに品質を追加しました。

- 品質0
- ☆1
- ☆2
- ☆3

高品質ほど次の値が有利になります。

- 回復アイテムの効果量
- ルーラのポーションの発動所要step
- 寿命
- 素材の売値

将来的には調合・鍛冶の完成品質にも材料品質を接続する予定です。

### 採集系スキル

以下を独立管理します。

- 採集 Lv
- 採掘 Lv
- 釣り Lv
- 木こり Lv

品質判定には、

- 対応スキルLv
- 採取地点の難度
- ミニゲーム成績
- 少量のランダム幅

を使います。

採集を繰り返すと対応スキルに経験が入り、レベルが上がります。

### 寿命を延長

v0.5より全体的にかなり長くしました。基礎寿命は仮値です。

- 薬草: 270 step
- 森キノコ: 240 step
- 川魚: 180 step
- 銀うろこの魚: 300 step
- ポーション: 720 step
- ルーラのポーション: 1500 step

さらに品質によって最大約2倍まで寿命が伸びます。

### 品質・寿命別スタック

バッグでは、同じアイテムでも以下が違えば別スタックになります。

- 品質
- 残り寿命

例:

- 薬草 品質0 / 寿命120step
- 薬草 ☆2 / 寿命330step

は別々に表示されます。

### 戦闘中のサブメニュー

戦闘コマンドを拡張しやすい構造へ変更しました。

- こうげき
- とくぎ → 技一覧
- じゅもん → 魔法一覧
- ぼうぎょ
- どうぐ → バッグ内の使用可能アイテム一覧

薬草やポーションは品質・寿命別のスタックから**どれを使うか選択**できます。

今後、技・魔法を追加しても同じリストUIへ増やせます。

### 倉庫

村の `持ち物` 画面を、

- バッグ
- 倉庫
- 道具屋

に分けました。

帰村しても拾った素材は自動で倉庫へ移りません。バッグに残ります。

バッグ画面から必要なスタックを倉庫へ送り、倉庫からバッグへ戻せます。

#### 倉庫内の生鮮品

倉庫では瓶・保存容器に入れている扱いにし、**寿命の減少速度がバッグの1/3**になります。

世界時間そのものは止まりません。

#### 倉庫容量

初期容量は100です。

- 100
- 160
- 240
- 360
- 520

の段階拡張を仮実装しています。拡張には徐々に高額なお金が必要です。

### 旧セーブ移行

v0.5以前の以下のデータをv0.6の品質スタックへ自動移行します。

- 通常素材
- 生鮮バッチ
- ポーション
- ルーラのポーション
- 旧 `armor` 装備スロット

移行品の品質は基本的に品質0になります。

## 継続中のシステム

- 27地点の双方向周辺マップ
- 朝 / 昼 / 夜を各30stepで管理
- レベルアップ時HP/MP非回復
- EXP即時反映
- 2徹夜目以降の疲労ペナルティ
- セーフティ / 準セーフティでのキャンプ
- バッグ容量
- 素材売却が主な金策
- 鍛冶屋依頼60step / 自作鍛冶ミニゲーム
- 調合は一旦保留
- 放置探索はUIから封印、コードのみ保持
