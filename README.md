# GrindQuest PWA v0.14

スマホ縦持ち前提の探索・採集・生産・コマンド戦闘PWA。

## v0.14 — 最大4人パーティ / 複数敵戦闘

### パーティ

- パーティ上限は4人
- 主人公を含め、キャラクターごとに以下を完全別管理
  - Lv / EXP
  - HP / MP
  - 7能力値
  - 装備
  - 作戦
  - APP（アディショナルパラメータポイント）
- レベルアップ時に APP +1
- APPは「強さ」画面の振り分けモードから任意能力へ投入可能
- Lvアップしても現在HP/MPは回復しない

### 村UI

村の上部表示を4人用に変更。

- 名前
- HP
- MP

だけを常時表示し、キャラ枠タップで前面メニューを開く。

- `強さ` → 新規ステータス画面
- `さくせん` → 行動方針変更

現在の作戦:

- めいれいさせろ
- ガンガンいこうぜ
- いのちだいじに

### 酒場

ミナト村に酒場を追加。

現在は戦士 **ガルド** 1人を加入 / 待機へ切り替え可能。

ガルドは主人公とは別のLv・EXP・能力・HP/MPを持つ。将来、別の街・イベント・ダンジョンなどから加入するキャラも同じ `characters / party` 構造へ追加できる。

### 複数敵戦闘

- ランダムエンカウントで複数体が出現可能
- 弱い地域では基本1〜3体
- 中程度では基本1〜2体
- 同一地域の敵テーブルから混成グループも生成可能
- シンボル敵・ボス・キャンプ襲撃は現状単体
- 敵1体ずつ独立したHP / 攻撃 / 守備 / 素早さを保持
- 同種複数時は A / B / C 表記
- 攻撃・特技は対象敵を選択可能
- 回復呪文・道具は対象味方を選択可能

### ターン処理

1ターンは味方全員＋敵全員の行動をまとめて処理する。

- `めいれいさせろ` の味方は順番にコマンド入力
- その他の味方は作戦に従って自動選択
- 全行動の `すばやさ + 小乱数` で行動順を決定
- 全員の行動が終わると1step進行
- 敵は生存中の味方から攻撃対象を選ぶ

### 装備

装備画面でもパーティキャラを切り替え可能。装備品は1個体を複数人が同時装備できない。
