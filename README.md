# GrindQuest PWA v0.41

スマホ縦持ち前提の「周辺フィールド探索・採集・帰路管理RPG」プロトタイプです。

フィールドは実際の村・森・川・山・遺跡周辺をノードと線に圧縮した地図として扱います。ノードはイベントではなく**場所**で、出来事・敵・資源状態は時間帯や探索状況で変化します。

## v0.4 の主な変更

### 戦闘を専用レトロJRPG画面へ

- エンカウント時に一度フィールドを暗転
- 暗転後、黒基調の専用戦闘画面へ遷移
- DQ / 初期ポケモンのような「敵表示・メッセージウィンドウ・コマンドウィンドウ」構成
- 1コマンドターン = 1ステップ
- 戦闘中にも朝昼夜、生鮮品の寿命、徹夜疲労が進行する

### ステップ時計を全システムで共有

- 30ステップごとに `朝 → 昼 → 夜`
- 90ステップで翌日
- 移動・戦闘・採集・睡眠を同じ `calendar.totalSteps` で管理
- 将来の調合・発酵・熟成も `timedProcesses` で同じ時計に接続可能

### 生鮮品の寿命

朝になった瞬間に消える方式を廃止し、取得時刻から寿命を数えます。初期値は仮です。

- 薬草: 75 step
- 森キノコ: 60 step
- 川魚: 105 step
- 銀うろこの魚: 135 step

村へ帰っても寿命は止まりません。探索中はバッグ、帰村後は倉庫に移るだけで、期限を超えると腐敗します。

### 睡眠と徹夜

村で眠る場合、1step睡眠で全快することはありません。

- 現在フェーズの残りが20step以上 → 次フェーズ開始まで睡眠
- 残り20step未満 → さらに次のフェーズ開始まで睡眠
- 村の睡眠: HP/MP全回復、徹夜疲労解除
- 2日分（180step）以上連続で起き続けると徹夜疲労開始
- 以後30stepごとに HP上限 / MP上限 / 攻撃 / 守備 が10%ずつ低下
- 現状はゲーム破綻防止のため最大70%低下で仮上限

### キャンプ

道具屋にキャンプセットを追加しました。

- 260G
- 容量5
- 再使用可能
- セーフティエリア: 安全に野営
- 準セーフティエリア: 35%の仮確率で襲撃
- 通常キャンプ: 不足HP/MPの70%を回復、徹夜疲労解除
- 襲撃時: 睡眠途中で戦闘へ移行、少量だけ回復

安全度は場所そのものに設定しています。

## 既存の中核

- 27地点の双方向周辺マップ
- 村外周のループ、森・川・山・遺跡への枝道
- 時間帯・地域別エンカウント
- 固定採集スポット（一探索につき一度）
- 採掘 / 釣り / 木こりミニゲーム
- 任意撤退なし。徒歩帰還か高価なルーラのポーション
- 敵はGを落とさない
- 素材売却が主な収入源
- バッグ容量管理
- 放置探索はUIから封印したままコードのみ保持

## バランスについて

v0.4の数値はすべてプロトタイプ値です。寿命、キャンプ回復量、襲撃率、徹夜ペナルティ開始点などは、ゲームループが固まってから調整する前提です。

## ローカル起動

```bash
python -m http.server 8080
```

`http://localhost:8080/` を開いてください。

## GitHub Pages

ビルド不要です。リポジトリへ中身をpushし、`Settings > Pages > Deploy from a branch > main / (root)` で公開できます。
