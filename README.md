# GrindQuest PWA v0.3

スマホ縦持ち前提の「周辺フィールド探索・採集・帰路管理RPG」プロトタイプです。

v0.2のSlay the Spire風縦マップから方向転換し、**実際の村・森・川・山・遺跡周辺を、ノードと線だけに簡略化したフィールド地図**として扱います。ノードはイベントではなく場所です。

## v0.3 の中核

- 27地点の広い周辺マップ
  - 村の外周を一周して戻れる
  - 森の奥、川・湖、山・採掘場、遺跡へ枝分かれ
  - 道は双方向。帰還も同じ道を歩く
- ランダムイベント
  - 場所自体は固定
  - 到着時の出来事は時間帯・地域で変化
  - 約18種の小イベントを初期実装
- 時間管理
  - 30ステップごとに `朝 → 昼 → 夜`
  - 90ステップで翌日
  - 地域・時間帯で敵テーブルが変わる
- 帰還
  - 任意撤退は廃止
  - 村まで歩いて戻る
  - 帰路でもエンカウントする
  - 高価な「ルーラのポーション」があれば即時帰還可能
- お金
  - 敵はGを落とさない
  - 持ち帰った素材を村で売るのが主な収入源
- 薬草とポーション
  - 薬草は探索中に採取/発見する生鮮品
  - 帰村時に残りは傷んで消滅
  - ポーションは保存可能だが高価
- バッグ容量
  - 素材・薬草・保存薬が容量を使う
  - 安物12 → 帆布20 → 大型32
  - 重い鉱石・魚・木材は容量を多く使う
- 固定採集スポット
  - 同じ探索中は一度しか利用できない
  - 次の探索では再び採れる
- ミニゲーム
  - 採掘: タイミング
  - 釣り: アタリ待ち
  - 木こり: 左右交互入力
- 放置探索
  - UIから封印
  - v0.2由来のコードとセーブ領域は残してある

## ゲームとしての狙い

「奥へ行けるか」だけでなく、**帰り道に何ステップかかるか、夜になるか、バッグに何を残すか、薬草を今使うか、高価なルーラを切るか**を考える探索ゲームです。

この共有カレンダーは、将来的に4人の主人公が別々の地域で日付を消費し、期限までに一つの場所へ集結するローグライト構造へ拡張できます。

## ローカル起動

```bash
python -m http.server 8080
```

`http://localhost:8080/` を開いてください。

## GitHub Pages

ビルド不要です。リポジトリへ中身をpushし、`Settings > Pages > Deploy from a branch > main / (root)` で公開できます。
