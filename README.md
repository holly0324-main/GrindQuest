# GrindQuest PWA v0.15

スマホ縦持ち前提の探索・採集・生産・コマンド戦闘PWA。

## v0.15 — 探索中の味方回復 / セーブ基準整理

### 探索中の回復アイテム

バックパックから薬草・ポーションなどを使うと、即主人公へ使用せず**対象の仲間を選択**する。

- 現在のパーティメンバーを一覧表示
- 各キャラのHPとHPバーを表示
- 対象選択後にアイテムを1個消費
- 2step進行
- 使用後にその場のエンカウント抽選
- 戦闘不能者は通常回復アイテムの対象外

回復アイテム処理は `characters / party` を直接参照するため、今後3人目・4人目が増えても主人公専用処理を追加する必要はない。

### セーブ互換の整理

v0.14で全員分の進捗をリセットしてパーティ制へ移行したため、**v0.14を新しい互換基準点**に変更した。

- v0.14セーブ → v0.15へ引き継ぎ
- `characters` と `party` をキャラクターデータの正本に統一
- 旧 `player` 単体フィールドをランタイム状態から廃止
- v0.13以前向けの複雑なキャラ・装備・アイテム移行処理を終了
- v0.13以前のセーブを読み込んだ場合は新規進行へ戻し、設定だけ引き継ぐ

これにより、今後の仲間追加・個別成長・キャラ別イベントで旧1人用データ構造を考慮する必要がなくなった。
