# GrindQuest PWA v0.17

スマホ縦持ち前提の探索・採集・生産・最大4人パーティ対応コマンドRPG PWA。

## v0.17 — Discovery / Battle Tactics / Forge & Equipment Shop

v0.16の機能別モジュール構造を維持したまま、発見状態・戦闘中作戦変更・鍛冶進行・武具販売を追加。

### 発見・図鑑

- 全アイテム・装備・モンスターに「知っている」状態を記録
- アイテム/装備は「知識あり」と「実際に入手済み」を別管理
- モンスターは「知識あり」と「実際に遭遇済み」を別管理
- 入手・ショップ/レシピで見る・遭遇・イベント/物語知識から解禁可能
- 初めて実物を入手した品は `✨ 初ゲット！ ✨` の全画面オーバーレイ
- 図鑑の未発見項目は名前・アイコン・詳細を伏せる
- モンスター図鑑の未発見ドロップも伏せる
- v0.16セーブの既存所持品/討伐済みモンスターは静かに発見状態へ補完し、移行時の初ゲット連打を防止

発見状態の実装は `src/game/discovery/`。図鑑表示組み立ては `src/game/encyclopedia/` に分離。

### 戦闘中の作戦変更

戦闘コマンドからパーティ全員の作戦を変更可能。

- めいれいさせろ
- ガンガンいこうぜ
- いのちだいじに

作戦変更自体はターンを消費しない。変更したキャラに入力済みの古い行動がある場合は破棄し、新しい作戦を即時反映する。

### 鍛冶

- 鍛冶一覧は一旦 `R1以上` の完成品だけ表示
- 必要素材に未発見品が1つでもあれば、そのレシピ自体を非表示
- 鍛冶屋への依頼は材料に加えて加工賃が必要
- 依頼品は従来通り60step後に完成
- 自作鍛冶ミニゲームの実装は維持
- ただし現在は `鍛冶技能 未習得` としてグレーアウト
- 将来 `state.skills.manualForge` を習得したら再利用できる構造

### 道具屋の武具売り場

ミナト村の道具屋に武器・防具売り場を併設。

現在はR1中心の常備品を部位横断の一覧で販売。ショップデータは `src/data/shops/` に分離されているため、今後は町ごとに別の品揃え/強さを設定できる。

## セーブ互換

v0.14を進捗互換の基準としている。

- v0.14 / v0.15 / v0.16 → v0.17へ正規化して引継ぎ
- v0.16以前に所持していた品は「入手済み」として静かに補完
- v0.13以前 → 進捗は新規化、設定のみ引継ぎ

## テスト
